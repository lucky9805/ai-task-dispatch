④ 如何配对

在③登记 Agent 后会得到一次性配对码。配对码只显示这一次，10 分钟内有效、只能用一次。把下面的命令复制到 Agent 所在机器执行即可。

  1. 服务端已在「Agent 管理中心」登记 Agent 并生成配对码（下方）。
  2. 在 Agent 所在机器执行换凭证命令，凭证保存在本机（权限 600），服务端只存哈希。
  3. 在同一台机器启动 Agent，它会用凭证只领取指派给自己的任务；未配对 / 被撤销的一律领不到。
